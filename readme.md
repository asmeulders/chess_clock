# C Chess Clock

This is a chess clock written in C that has many preset time controls as well as player name input.

## Installation

Be sure to have C installed. (TODO: I wrote this on Linux so check comaptibility with Windows.)

## Usage

```bash
# clone the repo
git clone https://github.com/asmeulders/chess_clock.git

# cd into project directory
cd ./chess_clock

# run the executable
./bin/chess_clock
```

Browse the menus and follow the instructions. Once you are in a game press the space bar to mark the end of your turn and have fun!
